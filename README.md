# traducao_Swords_-_Souls-_Neverseen_pt-br
## Sobre a Tradução e Créditos
Este repositório contém os recursos necessários para aplicar a tradução de Swords & Souls: Neverseen para português. O projeto foi concebido com o objetivo de trazer uma localização completa e de alta qualidade para os jogadores que desejam desfrutar da experiência na nossa língua, visto que o jogo não conta com suporte nativo.

Em termos de desenvolvimento, o processo de construção baseou-se na extração e modificação direta do banco de dados de localização do motor Unity, utilizando o sistema I2 Localization embutido nos pacotes de dados do jogo. Para aceder a esta estrutura interna sem recorrer a ferramentas de tradução externa em tempo real, foi empregue a excelente ferramenta UABEA (Unity Asset Bundle Extractor Avalonia), que permitiu descarregar e inspecionar o ficheiro LanguageSource presente nos ativos principais. A partir daí, procedeu-se à substituição estruturada do índice de texto em inglês por equivalentes adaptados para o português, preservando rigorosamente todas as etiquetas de formatação, marcadores de estilo, variáveis de nomes de utilizador e caracteres especiais exigidos pela engine para assegurar a estabilidade visual da interface.

Para viabilizar a distribuição pública deste trabalho de forma leve, segura e totalmente alinhada com as boas práticas da comunidade, optou-se por não partilhar os pacotes de dados originais do jogo, mas sim gerar um patch diferencial binário através do utilitário xdelta3. Este método foca-se exclusivamente nas alterações de texto efetuadas, resultando num ficheiro de patch extremamente compacto que pode ser fundido de forma automatizada pelo utilizador final através do DeltaPatcher, garantindo total compatibilidade tanto em sistemas Windows quanto em ambientes Linux.

Todo este trabalho de tradução e adaptação não teria sido possível sem o brilhante ecossistema de ferramentas de modding desenvolvido pela comunidade. Deixamos um agradecimento profundo e o devido crédito aos criadores do UABEA, da tecnologia xdelta e do DeltaPatcher, cujos projetos de código aberto e utilitários tornam viável a acessibilidade e a preservação de jogos independentes.
